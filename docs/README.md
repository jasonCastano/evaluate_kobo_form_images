# Documentation

Project documentation folder. Suggested layout:

| Folder | Content |
|--------|---------|
| `adr/` | *Architecture Decision Records*: major decisions with context and consequences. |
| `spikes/` | Time-boxed technical investigations (question, timebox, finding). |
| `research/` | Research notes and comparisons. |

> The summarized decision log lives in [`../CONSTITUTION.md`](../CONSTITUTION.md); ADRs go
> into detail when a decision deserves it.

Rules:

- One document, one topic.
- ISO dates (`YYYY-MM-DD`).
- Link each document from the constitution or the README when relevant.
- Never include real field data (farmers, enumerators, images); use synthetic examples.
